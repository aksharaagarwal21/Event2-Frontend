# IGNISIA 2025 · Event Website

The website for IGNISIA 2025, a placement and DSA workshop organised by the GeeksforGeeks student chapter at SRMIST.

## Features

- Hero section with an animated tagline and a countdown timer to the event
- About, speakers, sponsors and event timeline sections
- FAQs and social links
- Scroll animations and a registration popup

## Tech stack

React · Vite · Tailwind CSS · Material UI · Framer Motion

## Run locally

```bash
npm install
npm run dev
```
